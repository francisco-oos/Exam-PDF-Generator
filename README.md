# Exam-PDF-Generator · Adaptación empresarial

Repositorio de trabajo para un generador local de cuadernillos, hojas de respuestas y claves en acetato.

**Procedencia:** basado en la idea de [UzielLopez/Exam-PDF-Generator](https://github.com/UzielLopez/Exam-PDF-Generator) (2020), disponible bajo licencia MIT. Se preserva su aviso de atribución. Esta adaptación fue reimplementada y auditada; no es una copia exacta del código original.

La implementación estará en una rama de trabajo para revisión antes de integrarla a `main`.
